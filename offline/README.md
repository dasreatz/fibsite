# Локальний кабінет
Це повний погоджений дизайн попереднього HTML з оновленими кадровими бланками. Він не підключений до живої бази, має локальні демонстраційні дані і не призначений для публікації. Відкривати лише локально. Не вводьте реальних персональних даних чи ключів. Для спільної роботи використовуйте серверний `/cabinet/`. Build не копіює цю папку в dist.
